# 언어 설정

## 응답 언어

- **항상 한국어로 응답하세요.**
- 모든 설명, 안내, 코멘트는 한국어로 작성하세요.
- 코드 주석은 영어로 작성하세요.
- 기술 용어는 필요에 따라 영어를 병기할 수 있습니다 (예: "시그널(Signal)").

## 예외 사항

- 코드 자체(변수명, 함수명, 클래스명 등)는 영어 명명 규칙을 따릅니다.
- 에러 메시지나 로그는 원본 언어(주로 영어)를 유지합니다.
- 공식 문서나 외부 리소스 링크는 원본 언어를 유지합니다.
